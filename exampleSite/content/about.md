title: About this unit
---

This is the demonstration site for **PDA**, a Hugo theme drawn from late-1990s field computers: olive housing, phosphor type on a dark LCD, tabbed lists.

It is not Ledger (the board-deck slideshow) and it is not Nightscape (the cityscape blog). Body copy is set in Roboto Mono so the screen stays readable; chrome uses Share Tech Mono.
